## ✨ Fitur Baru di Versi Ini

1. 🎁 **Event 7 Hari Login (Daily Rewards)**:
   - Muncul otomatis saat pertama kali login game.
   - Klaim hadiah koin setiap hari (Hari 1 hingga Hari 7).
   - Setelah diklaim, hadiah hari tersebut terkunci hingga 24 jam berikutnya.
   - Hadiah puncak Hari ke-7: **3.000 Koin + Skin Kaisar Emas (Golden Emperor)**!
   - Tombol cek event kapan saja di Lobby utama.

2. 🌍 **Arena Luar & Pilihan Mode Permainan**:
   - Label diubah menjadi **Arena Luar**.
   - **Mode Arena Luar (Klasik)**: Santai bertumbuh dan mendominasi arena tanpa batas waktu.
   - **Mode Time Attack (3 Menit)**: Berkejaran dengan waktu untuk mencetak skor dan kill terbanyak dengan pengganda skor 2x lipat!
   - **Mode Battle Royale**: Safe Zone lingkaran arena menyusut perlahan seiring waktu dan bot tidak akan respawn—jadilah cacing terakhir yang bertahan!

3. 🕹️ **Kustomisasi Posisi Joystick & Tombol Boost**:
   - Posisi default diatur lebih nyaman dan tidak menempel di pojok layar.
   - Menu **Edit Posisi Joystick & Boost** di Pengaturan:
     - Geser slider jarak horizontal dan vertikal untuk Joystick (posisi kiri).
     - Geser slider jarak horizontal dan vertikal untuk Tombol Boost (posisi kanan).
     - Tombol reset posisi jika ingin kembali ke tata letak default.

4. 👁️ **Pratinjau (Preview) Skin Sebelum Membeli**:
   - Di Lemari Skin & Aksesoris, klik skin atau aksesoris mana pun yang terkunci untuk langsung melihat bagaimana cacing meliuk-liuk memakainya di animasi preview atas sebelum memutuskan membeli.

5. ⚔️ **Notifikasi Kill Musuh (Kill Feed Banner)**:
   - Efek animasi banner di bagian atas saat cacing musuh berhasil dieliminasi.
   - Menampilkan nama musuh, bonus koin, dan kombo beruntun (*Double Kill, Triple Kill*, dst.) dengan efek suara & getaran haptik.

6. ❤️‍🩹 **Lanjutkan (Revive) Cacing dengan Koin**:
   - Saat cacing mati, pemain diberi pilihan untuk menghidupkan kembali cacingnya.
   - Biaya koin dihitung dinamis sesuai seberapa besar/panjang cacing pemain saat tumbang.
   - Cacing bangkit kembali dengan **perlindungan kebal selama 6 detik**!

## 🛠️ Teknologi

- **Platform**: Android
- **Bahasa**: Kotlin (100%)
- **UI & Graphics**: Jetpack Compose Canvas Renderer + Material Design 3
- **Audio & Haptik**: Android SoundPool / PCM AudioTrack & Vibrator API
- **Data Persistence**: SharedPreferences / Repository Pattern

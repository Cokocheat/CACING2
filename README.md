# Nana Tayantuh 🐛🎮

**Game Cacing Seru Android dalam Mode Landscape Luas dengan Arena Dinamis, Bot AI Cerdas, Berbagai Makanan & Ramuan Power-up, serta Kustomisasi Skin Cacing.**

---

## 📥 Unduh File APK

File APK sudah di-build dan siap diinstal langsung di perangkat Android:
- 👉 **[Download nana_tayantuh.apk](./release/nana_tayantuh.apk)** (di folder `release/`)
- Atau unduh langsung file `nana_tayantuh.apk` dari root direktori repositori ini.

---

## ✨ Fitur Game

- 🕹️ **Mode Landscape Luas**: Pengalaman kontrol arena cacing yang nyaman dan responsif di layar sentuh.
- 🤖 **Bot AI Cerdas**: Cacing AI penantang dengan algoritma navigasi, penghindaran tabrakan, dan perburuan makanan.
- ⚡ **Dorongan Cepat (Boost)**: Gunakan energi untuk melaju kencang dan mengepung cacing lain.
- 🧪 **Ramuan & Power-Up**: Magnet makanan, pengganda skor, dan kecepatan ekstra.
- 👕 **Lemari Skin (Wardrobe)**: Berbagai variasi skin cacing unik dan penuh warna.
- 🏆 **Papan Skor & Rekor**: Mencatat skor tertinggi, jumlah kill, panjang cacing, dan koin yang dikumpulkan.
- 🔊 **Efek Suara & Haptik**: Audio interaktif dan getaran haptik responsif saat bermain.

---

## 🛠️ Teknologi

- **Platform**: Android
- **Bahasa**: Kotlin (100%)
- **UI & Graphics**: Jetpack Compose Canvas Renderer + Material Design 3
- **Audio & Haptik**: Android SoundPool & Vibrator API
- **Data Persistence**: SharedPreferences / Repository Pattern
